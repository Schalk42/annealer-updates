How to update

  1. Connect the machine to WiFi via the Annealer-Setup hotspot: with the machine idle, hold MODE + TIME together for 3 s (or type wifi setup in serial), join the Annealer-Setup WiFi on your phone and pick your network.
  2. Then, with the machine idle, hold MODE (longer than 1.2 s) or type update in serial.
  3. The controller downloads the new firmware over HTTPS, checks its SHA-256, installs it and restarts. All outputs stay off during the update. If anything fails, it keeps running the current firmware.
