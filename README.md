# Annealer firmware updates

Public GitHub Pages site that serves over-the-air (OTA) firmware updates for the
ESP32 annealer controller.

- Site: https://schalk42.github.io/annealer-updates/
- Manifest read by the controller: https://schalk42.github.io/annealer-updates/firmware.json
- Version history: `history.json`
- Images: `firmware/annealer-<version>.bin`

Do not edit these files by hand. They are generated by `tools/publish.sh` in the
private `annealer-firmware` repository.
